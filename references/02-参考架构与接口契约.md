# 02 · 参考架构与接口契约

> 描述一套可复刻的「Agent 状态监控小系统」参考实现。端点名、计数、参数取自参考实现 **W29**（2026-11-16）现役配置，用于说明**契约长什么样**；复刻时按自己的页面与硬件重算，不照抄数值。

## 一、五层架构

```
[ Agent 运行时 hooks / 适配器 ]──写事件 jsonl / 状态文件
            │
            ▼
[ 采集 · 哨兵 · 门户 py ]  8420 ── /agents 明细、/__ctl 控制、访问码配对
            │                          │
            │                          ▼ HTTP /cmd
            │                 [ ESP32-S3 状态灯 + 0.96" OLED ]
            │                  · NVS 保存三色/亮度（掉电持久化已生效）
            │                  · 无心跳强制灭灯（防假状态）
            │                  · 板载 AP 应急页 192.168.4.1
            │                  · 无网页配网，SSID 硬编码 config.h
            ▼
[ 8080 自包含 HTTP 服务 + 单文件 SPA ] ← 电脑 / 手机浏览器（同 WiFi）
   · /net + /api 真值 → 换网向导同网判定（纯前端，零固件依赖）
   · /stats 自带逐条 csv → 四维度热力图（真实数据、真实覆盖天数）
            │
            ▼
[ 公网静态连接向导 ]  仅做环境识别与入口指引，无后端、不造假数据
```

**单向原则**：数据从 Agent 运行时往下流；控制指令从浏览器经同源代理下发。任何一层取不到上游数据时显示「未知 / 离线」，不生成演示值；真实覆盖不足时标注「数据积累中，暂不绘满」。

## 三、接口契约（参考命名）

| 端点 | 提供方 | 用途 | 失败语义 |
|---|---|---|---|
| `GET /api?raw=1` | 8080 看板服务 | 当前状态、运行时长、计数快照；W29 向导另取 `ip` / `ssid` / `rssi` 作同网判定真值 | 超时 4s 降级，不立刻切 OFFLINE |
| `GET /net` | 8080 | 运行时返回真实局域网 IP / 固定 `.local` 域名 / `lan_url` | 失败时页面用 `network.json` 兜底值 |
| `GET /stats` | 8080 | 窗口事件数、来源统计（含 `trae`，保留 `tree` 别名）、**自带逐条 `csv` 明细**（`ts,kind,src,dur_s,seq`） | 静默降级；无 csv 时热力图才回退本地 `EVENTS` 演示数据并如实标注 |
| `GET /events` / `/audit` | 8080 | 事件时间线 / 审计记录 | 静默降级，合并倒序展示 |
| `GET /health` | 8080 | 8 盏健康灯（服务 / 采集 / 统计 / 配置 / 板端 / 推屏 / 控制 / 天气） | 判据不明显示灰色「未知」，不误报 FAIL |
| `GET /agents` | 8420 门户 | Agent 来源明细（用于按 `ago` 最小归属推断本轮来源） | 板端不可达时来源计数如实为 0 |

| `GET /align` | 8080 | 前端 / 服务端 / 板端三方状态对齐 | work 子态 `waiting/generating/done` 存在瞬时竞态，允许复跑 |

| `POST /__pair`、`/__ctl` | 8420 | 访问码确认后种 Cookie、硬件动作 | 访问码不进 302 / Referer，令牌文件 0600 |

## 四、W29 新增能力契约

- **连接状态单一出口**：`renderLinkState()` 统一驱动 `modeBanner` / `netHint` / `statsFeedback` / `linkPill` 四容器（模式 / 公网 / 离线 / 演示四态 + 退避详情）；`netHint(r)` 只写 `NETQ.reason` 再调单一出口；`autoProbe` 不直写 DOM。三容器 id 与 `data-fb` / `role` 契约保留。
- **监控暂停单点**：`setMonitorPaused(v)` 合并原双实现，按钮统一「暂停监控 / 恢复监控」并同步 `aria-pressed`，状态变量单点写入 `MON_PAUSED` / `DEV.paused`；「暂停监测」全页归零。
- **换网向导（纯前端）**：连接卡内 `<details class="net-wiz">`，含 `net-wiz-state` 状态行、救援 AP `192.168.4.1/info`、地址复制入口（复用既有 `netCopyHint`）。同网判定用 `/net` 的 `ip` / `lan_url` 与 `/api` 的 `ip` / `ssid` / `rssi`：电脑与板端 IP 前三段相等判同网；板端失联、`file` / `static`、演示模式分别给不同文案，**不伪造在线**。文案必须写明固件无网页配网、换 WiFi 须改 `config.h` 重编译烧录；改地址改 `network.json` 后 `--apply`。
- **热力图四维度**：`<select class="heat-dim">` 四维度（时段 / 来源 / 状态 / 按日），用 class 选择器，**不新增 id / button / setInterval / style / script**。`renderHeat(a)` 单一渲染出口，优先取 `/stats` 自带 `csv` 逐条明细，`heatMatrix` / `svgHeatM` 做 12 列 × 2 小时聚合，`heatCover` 用首末事件算**真实覆盖天数**并诚实标注「真实事件 / 演示数据 覆盖 N 天 / 窗口 N 天 · 数据积累中，暂不绘满」；空维度显示「该维度暂无事件 · 不绘制推测数据」。来源映射按命名铁律写 **TRAE CN**。**不设月 / 季选项**：真实事件仅约 2.43 天，月/季必为空图；月/季聚合须先做「事件按月归档」前置（P2′ 已报价获准、另开会话立为 W30）。
- **状态 elId 通用契约**：正则提取全部 `patchConfig` 状态 elId，逐个比对 DOM `id` 集合，任一悬空即 FAIL。W29 A4 修后 6 个历史悬空串清零、统一由真实存在的 `ovSaveTag` 承载；这是「共用全局状态位」，不是逐行就地状态。
- **引导与偏好**：引导收起写 `localStorage['wb.guide.seen']`，`initV2()` 读回；三色偏好 `localStorage['wb.board.v1']` 必须合并语义写入，恢复段早于任何回写。

## 五、前端契约（计数式断言范例）

- 单文件 SPA：`index.html` 内联 CSS/JS，配 `sw.js` 离线缓存与 `manifest.json`。
- 参考实现现役计数：`id` **253** 个全唯一 / `button` **109** / `setInterval` **2** / `style` **2** / `script` **3**。新功能**不得新增定时器**，复用唯一 `tick` 调度器；W29 删 7 个重复按钮（116 → 109），用 class 选择器新增能力而不动计数契约。
- 体积护栏：200,000 B 上限 + `min_headroom_bytes` 4,000 B ⇒ **硬上限 196,000 B**；现役 195,966 B / 余量 **4,034 B** / 可新增上限仅 **34 B**。护栏写进验证脚本与 manifest；改版同步 bump SW 缓存名（现役 `wb-board-w29-v1`），否则手机端拿不到新页。
- 近预算改动：先按未压缩页面做精确替换（压缩后锚点会失配），再用带 AST / 断言字面量保护的压缩器（默认 dry-run，`--apply` 才写盘）；**只删安全换行 / 注释不改规范化哈希**，删空白后函数结束形如 `}function …`，按 `\n}\n` 提取函数体的断言改为按下一个 `function` 锚定。代价是页面零缩进、可读性下降。
- 网络层：三档轮询（fast 心跳 / mid 模式 / slow 事件）+ 失败翻倍退避（5→10→20→30s 封顶）+ 成功折半恢复 + 页面隐藏暂停；断流宽容窗口 15s。
- 偏好：`localStorage['wb.board.v1']` 必须**合并语义写入**（先读旧值再写回），恢复段早于任何回写动作；页面加载不静默下发硬件。

> 上述计数是「契约可被断言化」的示例，不是复刻目标值。换页面就重算计数与基准哈希。

## 七、固件要点

- `FW_VER` 单值标识；编译验证 EXIT=0 后才能烧；烧录采用整片备份 → 只写 `0x10000` 应用分区 → 读回 md5 一致 → `/api ver` 回读一致。
- `wbSaveParams()` 把 `pb/pg/pr/bv`（三色与音量）写 NVS，`wbInit()` 上电读回并调用 `wbLedSetPct()`；亮度/RGB 掉电持久化**早已实现且生效**，冷启动实测 `nvsok=1` 且参数 ≠ 出厂默认。**`wb_bv` 是蜂鸣器/功放音量，不是总亮度**；硬件只有 b/g/r 三色百分比，`light.brightness` 是软件缩放系数。
- **无心跳强制灭灯**（`wbstate.h` 两处）是防「假蓝 / 假绿」的设计，勿删。「没接电脑」≠「没心跳」：板子走 WiFi 收心跳，服务在跑即在线。
- 中文 OLED 需按 UTF-8 字符边界裁剪（参考 `w8DrawU8()`），`gW8Aux[][40]` / `task[40]` / `W8_MSG_HOLD_MS 8000` 为显示缓冲与消息保持时间；推送文本维持 W27 ASCII 短码 `T<n> A<n> <range>`（板端 `gW8.msg[32]` 仅 31 字节）。
- 板载 AP（现役 `ESP32-Direct` → `192.168.4.1`）内嵌于 `web_page.h`，改页面须重新烧录。**固件明确无网页配网**（`wb_light.ino` / `config.h` / `web_page.h` 均有说明，SSID 硬编码，系运维负责人主动精简），换 WiFi 须改 `config.h` 重编译烧录；前端只能做纯前端换网向导。
- A/B 互斥：门户 `k_fw` 交换已在 W16 撤销，日后烧固件勿恢复。
