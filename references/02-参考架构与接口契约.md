# 02 · 参考架构与接口契约

> 描述一套可复刻的「Agent 状态监控小系统」参考实现。端点名、计数、参数取自参考实现 W28 现役配置，用于说明**契约长什么样**；复刻时按自己的页面与硬件重算，不照抄数值。

## 一、五层架构

```
[ Agent 运行时 hooks / 适配器 ]──写事件 jsonl / 状态文件
            │
            ▼
[ 采集 · 哨兵 · 门户 py ]  8420 ── /agents 明细、/__ctl 控制、访问码配对
            │                          │
            │                          ▼ HTTP /cmd
            │                 [ ESP32-S3 状态灯 + 0.96" OLED ]
            │                  · NVS 保存三色/亮度
            │                  · 无心跳强制灭灯（防假状态）
            │                  · 板载 AP 应急页 192.168.4.1
            ▼
[ 8080 自包含 HTTP 服务 + 单文件 SPA ] ← 电脑 / 手机浏览器（同 WiFi）
            │
            ▼
[ 公网静态连接向导 ]  仅做环境识别与入口指引，无后端、不造假数据
```

**单向原则**：数据从 Agent 运行时往下流；控制指令从浏览器经同源代理下发。任何一层取不到上游数据时显示「未知 / 离线」，不生成演示值。

| 路径 | 职责 | 约束 |

| `README.md` | 总入口：访问地址、目录地图、日常命令、边界与现役状态 | 现役真值只写在这一节的表格里，编年史章节的中间值不改 |

| `sync_runtime.py` | 唯一真源 → 部署镜像同步通道 | `--check` 只读 / `--apply` 重建 / `--rollback` 回滚 / `--sync-links` 显式下发链路脚本 |

## 三、接口契约（参考命名）

| 端点 | 提供方 | 用途 | 失败语义 |
|---|---|---|---|
| `GET /api?raw=1` | 8080 看板服务 | 当前状态、运行时长、计数快照 | 超时 4s 降级，不立刻切 OFFLINE |
| `GET /net` | 8080 | 运行时返回真实局域网 IP / 固定 `.local` 域名 | 失败时页面用 `network.json` 兜底值 |
| `GET /stats` | 8080 | 窗口事件数、来源统计（含 `trae`，保留兼容别名） | 静默降级 |
| `GET /events` / `/audit` | 8080 | 事件时间线 / 审计记录 | 静默降级，合并倒序展示 |
| `GET /health` | 8080 | 8 盏健康灯（服务 / 采集 / 统计 / 配置 / 板端 / 推屏 / 控制 / 天气） | 判据不明显示灰色「未知」，不误报 FAIL |
| `GET /agents` | 8420 门户 | Agent 来源明细（用于按 `ago` 最小归属推断本轮来源） | 板端不可达时来源计数如实为 0 |
| `POST /ctl` | 8080 | 同源代理，把控制动作转给门户 / 板端 | 成败以回读为准，不用本地猜测 |
| `GET /align` | 8080 | 前端 / 服务端 / 板端三方状态对齐 | work 子态 `waiting/generating/done` 存在瞬时竞态，允许复跑 |
| `POST /preview` | 8080 | OLED 预览内容推送，含 `echoed != pm` 强校验 | 告警版式不在白名单内 |
| `GET /api ver`、`/cmd?do=wbset` | ESP32 板端 | 固件版本回读 / 三色亮度设置并落 NVS | 断电 / 断网记环境态 |
| `POST /__pair`、`/__ctl` | 8420 | 访问码确认后种 Cookie、硬件动作 | 访问码不进 302 / Referer，令牌文件 0600 |

## 四、前端契约（计数式断言范例）

- 单文件 SPA：`index.html` 内联 CSS/JS，配 `sw.js` 离线缓存与 `manifest.json`。
- 参考实现现役计数：`id` 253 个全唯一 / `button` 116 / `setInterval` 2 / `style` 2 / `script` 3。新功能**不得新增定时器**，复用唯一 `tick` 调度器。
- 体积护栏：200,000 B 上限 + 4,000 B 最小余量，写进验证脚本与 manifest；改版同步 bump SW 缓存名（如 `wb-board-wXX-vN`），否则手机端拿不到新页。
- 网络层：三档轮询（fast 心跳 / mid 模式 / slow 事件）+ 失败翻倍退避（5→10→20→30s 封顶）+ 成功折半恢复 + 页面隐藏暂停；断流宽容窗口 15s。
- 偏好：`localStorage['wb.board.v1']` 必须**合并语义写入**（先读旧值再写回），恢复段早于任何回写动作；页面加载不静默下发硬件。

> 上述计数是「契约可被断言化」的示例，不是复刻目标值。换页面就重算计数与基准哈希。

## 五、固件要点

- `FW_VER` 单值标识；编译验证 EXIT=0 后才能烧；烧录采用整片备份 → 只写 `0x10000` 应用分区 → 读回 md5 一致 → `/api ver` 回读一致。
- `wbSaveParams()` 把 `pb/pg/pr/bv`（三色与亮度）写 NVS，`wbInit()` 上电读回并调用 `wbLedSetPct()`；参数在板子 Flash，不依赖电脑。
- **无心跳强制灭灯**（`wbstate.h` 两处）是防「假蓝 / 假绿」的设计，勿删。「没接电脑」≠「没心跳」：板子走 WiFi 收心跳，服务在跑即在线。
- 中文 OLED 需按 UTF-8 字符边界裁剪（参考 `w8DrawU8()`），`gW8Aux[][40]` / `task[40]` / `W8_MSG_HOLD_MS 8000` 为显示缓冲与消息保持时间。
- 板载 AP（`ESP32-Direct` → `192.168.4.1`）内嵌于 `web_page.h`，改页面须重新烧录。

## 六、复刻前必须替换 / 脱敏的值

| 类别 | 示例 | 处理 |
|---|---|---|
| 网络 | `lan` IP、`host` `.local` 域名、`board_ip`、mDNS、端口 | 全部改 `network.json`，同步重建 |
| 凭据 | `secrets.h`（WiFi 密码）、`lan_token`（0600）、`sharecode`、访问码 | 只用 `.example` 模板；不外发、不写进文档 |
| 平台 | 应用卡片 `.genie`、线上站点 host、`app_id`、发布镜像绝对路径 | 换环境后按新平台重注册，旧链接不必复用 |
| 身份 | 门户 A/B 方案下的 `k_fw` 交换、历史 git 仓库路径 | 明确互斥决策，勿把已撤销的兼容开关恢复 |
| 计数 | `CANON_BASELINE`、INVENTORY md5、验证项数、体积护栏 | 首次跑通后重算并在编年史留痕 |
