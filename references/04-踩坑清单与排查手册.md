# 04 · 踩坑清单与排查手册

> 按「现象 → 根因 → 处置 → 预防」组织，全部来自真实排障。排查顺序建议：先跑只读体检，再按本表定位，最后才动代码。

## A · 环境与部署

**A1 · 服务起不来 / 读不到项目文件**
现象：launchd 启动后静默失败，日志无报错。根因：macOS TCC 不给 launchd 读 `~/Documents` 的权限。处置：运行时统一从 `~/.workbuddy/wblight/` 镜像加载；由同步脚本保证与真源逐字节一致。预防：把「运行时注册点在目录外」写进 README 边界，不做零镜像幻想。

**A2 · 手工搬目录后 hook 报错、`.git` 消失**
现象：整理文件夹后链路断、版本库不见。根因：hooks 软链 / plist 指向绝对路径，移动即失联。处置：恢复软链与 plist 指向，重跑链路自检（113 项）。预防：路径只改 `paths.json`，用 `--apply` 同步；禁止整目录手工搬移。

**A3 · 批量替换 `.workbuddy` 路径**
现象：替换后状态灯彻底不响应。根因：链路 py 里的这些路径是**镜像内部运行时路径**（状态 / 令牌 / 日志 / 锁），不是外部依赖。处置：从 `02-状态灯链路/` 源副本恢复，必要时 `--sync-links` 显式下发。预防：源码副本只做版本管理，不做路径「清洗」。

**A4 · 8080 端口不通**
现象：体检端点 FAIL。根因：launchd `bootstrap/load` 在当前 namespace 失败（服务疑似由宿主应用持有），或自愈托管进程退出。处置：先查 keepalive 进程与镜像同步状态；重启宿主应用 / 重新登录后 plist 应恢复正规常驻。预防：体检报告里区分「服务未跑」与「代码故障」，不盲目重启。

**A5 · IP 漂移后手机打不开**
现象：收藏的 `192.168.x.x` 失效。根因：DHCP 重分配。处置：改用固定 `.local` 域名；页面调 `/net` 显示当前 IP。预防：IP 只写 `network.json`，永远不硬编码进 HTML。

## B · 前端与数据

**B1 · 偏好调好重进被重置（最典型）**
现象：三色滑块调好，刷新后回默认。根因：`savePrefs()` 无 rgb 字段、`commitRgb()` 只下发硬件不落盘、`setState('RUN')` 早于 `loadPrefs()`；更隐蔽的是 `init()` 里 `setRange('24h')` / `autoProbe` 在恢复之前就调 `savePrefs()`，把偏好覆写成 `rgb:null`。处置：`savePrefs()` 改成**合并语义**（先读旧值，`rgb:DEV.manualRgb?DEV.rgb:(old.rgb||null)`），恢复段早于 `toggleLock()` 等回写。预防：只改「存 / 读」不做合并，静态断言会全绿、刷新仍丢值 —— 必须跑真浏览器往返。

**B2 · 静态断言全绿但功能没验到**
现象：老基线 504 项全 PASS，新功能却坏的。根因：老断言不覆盖新代码。处置：每个新功能建独立专项（`bl=False`），并做真浏览器往返。预防：把「老基线全绿 ≠ 新功能已验」写进验收清单。

**B3 · 手机刷新拿不到新页面**
现象：改了 HTML，手机还是旧版。根因：SW 缓存名没 bump。处置：bump SW 缓存名（如 `wb-board-wXX-vN`）与 `budget_revision` 同步更新。预防：把缓存名一致性纳入体积 / 预算断言。

**B4 · 公网静态站误报「连接中断」**
现象：线上预览页一直显示断线红条。根因：静态站无后端，却执行了本地服务的探活逻辑。处置：按 `env=static` 分支降级为连接向导页，只做环境识别与入口指引。预防：无后端就诚实说明，不造演示数据。

**B5 · 某来源计数恒为 0**
现象：TRAE CN 一直 0。根因：8080 `_derive_event()` 三处把 `src` 写死，`/api.agsrc` 只有 top 来源。处置：改为取 `/agents` 明细按本轮 `ago` 最小归属（短超时 + 好值缓存，失败回落 `agsrc`）；`/stats` 增 `trae` 并保留兼容别名。预防：来源归属必须基于明细，不要用聚合值猜。

**B6 · 板端离线时来源计数为 0 被当成 bug**
现象：体检或页面显示 0。根因：`/agents` 不可达属正常环境态。处置：如实显示 0，等板端恢复且有真实活动才有计数。预防：环境态记 WARN，不伪造数据、不判 FAIL。

**B7 · `CANON_BASELINE` 失配**
现象：体检报基准哈希不符。根因：改了功能代码。处置：重算并在 `VERSION.md` 留痕（写明前后值）；仅删空白 / 注释不应改变该值。预防：禁止直接改常量「让它变绿」。

**B8 · 对齐断言偶发抖动**
现象：`/align` work 子态 `waiting` vs `generating` 不一致。根因：Agent 运行时状态切换竞态，非程序故障。处置：静置或独立复跑；体检内置隔 2s 复跑一次，通过记 WARN。预防：不把瞬时竞态升级为代码改动。

## C · 硬件与验收

**C1 · 预览红绿反色 / 颜色口径不一致**
现象：页面预览与实物灯颜色相反。根因：固件与前端颜色映射不同。处置：修固件并烧录；同时撤销门户侧临时的 `k_fw` 交换（A/B 方案互斥）。预防：以后再烧固件切勿恢复已撤销的交换开关。

**C2 · 亮度掉电丢失的误判**
现象：怀疑「没接电脑就不保存」。根因：混淆两条链路 —— 浏览器偏好在 `localStorage`，硬件参数在固件 NVS（`wbSaveParams()` / `wbInit()` 读回）。处置：以冷启动 `/api` 回读 `nvsok` 与 `wb_b/g/r/bv` 实证。预防：文档里明确「本轮未碰固件」≠「固件没有该功能」。

**C3 · 无心跳却显示蓝 / 绿**
现象：板子还亮着旧状态，误导人以为在线。根因：缺失效保护。处置：保留 `wbstate.h` 无心跳强制灭灯。预防：灭灯逻辑是安全设计，不要为了「好看」删掉。

**C4 · 烧录失败**
现象：串口写入失败。根因：数据线只能供电不能传数据。处置：换 Type-C 数据线直连；整片备份 → 只写 `0x10000` → 读回 md5 一致 → `/api ver` 回读一致。预防：`flash.md` 写清前置检查与回退路径。

**C5 · 中文 OLED 乱码 / 截断**
现象：中文字符被切成半个。根因：按字节裁剪破坏 UTF-8 字符边界。处置：按字符边界裁剪（参考 `w8DrawU8()`）。预防：显示缓冲与消息保持时间（`W8_MSG_HOLD_MS`）一起校验。

**C6 · 把人工验收写成 PASS**
现象：报告里三入口颜色「已验证」但没人看过。处置：验收清单单列「需人工在场项」：按键红双闪 + 滴滴声、OLED 双屏并排目视、真机断电重启验自启、`--act` 实板下发、iOS 安全区 / 深色 / 320–430px 目视。预防：脚本不代签、不伪报。

## D · 协作与成本

**D1 · 单会话串多个任务导致成本暴涨**
现象：一次会话串 6 个独立任务、反复重发大上下文。处置：一任务一会话；任务收尾提醒新开会话；跨会话用记忆文件传上下文。预防：批量执行相关命令、只读需要的行、一次全量复验，不「跑一步看一眼」。

**D2 · 先重建后诊断**
现象：没看清现状就 `--apply`，把偏差刷进清单。处置：先 `health_check.py`（只读）确认起始状态，再重建。预防：把「体检只诊断、`--apply` 才重建」写进日常命令表。
